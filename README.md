# ⚽ Football Player Market Value Predictor

Predicts a football player's market value (in EUR) using a Random Forest
Regressor trained on the [Transfermarkt Player Scores dataset](https://www.kaggle.com/datasets/davidcariboo/player-scores)
(Kaggle), served through a Gradio web interface.

**Live demo:** https://huggingface.co/spaces/mrcolonthree/player_market_value_prediction

---

```

├── player_rf_pipeline.pkl               # Trained model (generated by the notebook)
```

## Setup (after cloning)

### 1. Clone the repository

```bash
git clone https://github.com/abdullah-al-monir/player_market_value_prediction.git
cd player_market_value_prediction
```

### 2. Create and activate a virtual environment

**Windows (Git Bash / MINGW64):**
```bash
python -m venv venv
source venv/Scripts/activate
```

**Windows (Command Prompt):**
```bash
python -m venv venv
venv\Scripts\activate.bat
```

**macOS / Linux:**
```bash
python -m venv venv
source venv/bin/activate
```

You should see `(venv)` appear at the start of your terminal prompt once activated.
**Every command below must be run with the venv active**, in the same terminal.

### 3. Create an empty `requirements.txt`

**Windows (Git Bash / MINGW64):**
```bash
touch requirements.txt
```

**Windows (Command Prompt):**
```bash
type nul > requirements.txt
```

**macOS / Linux:**
```bash
touch requirements.txt
```

### 4. Install the required libraries into the venv

```bash
pip install pandas numpy scikit-learn gradio spaces ipykernel
```

`ipykernel` is needed so this venv can be selected as the notebook's kernel
in Jupyter/VS Code.

### 5. Freeze the installed libraries into `requirements.txt`

```bash
pip freeze > requirements.txt
```

This locks `requirements.txt` to the exact versions installed in your venv —
important because the saved `.pkl` model is tied to the scikit-learn version
used to create it.

## Running the project

### Step 1 — Train the model (generates `player_rf_pipeline.pkl`)

Open `player_market_value_prediction.ipynb` in Jupyter or VS Code.

**Important:** set the notebook's kernel to **this project's `venv`**
(not `base` or any other environment) before running — otherwise the saved
`.pkl` file may be incompatible with the scikit-learn version `app.py`
loads it with later.

Then run all cells. This will:
- Load and preprocess `players.csv`
- Build a preprocessing + Random Forest pipeline
- Run 5-fold cross-validation
- Run hyperparameter tuning (`RandomizedSearchCV`)
- Evaluate the best model on a held-out test set
- Save the final pipeline to `player_rf_pipeline.pkl`

This step takes a few minutes due to the hyperparameter search.

### Step 2 — Launch the Gradio app

```bash
python app.py
```

This will start a local web server (typically at `http://127.0.0.1:7860`)
where you can fill in a player's profile and get a predicted market value.

## Troubleshooting

**`ModuleNotFoundError: No module named 'gradio'` (or pandas/sklearn/spaces)**
Your venv isn't active in this terminal. Run the activation command from
Step 2 above, then retry — activating it in an IDE's notebook kernel does
**not** activate it in a separate terminal window.

**`InconsistentVersionWarning` / `AttributeError` when loading the `.pkl` file**
The model was trained with a different scikit-learn version than the one
currently installed. Re-run the notebook (using the venv kernel) to
regenerate `player_rf_pipeline.pkl` with your current environment's
scikit-learn version.

**Predictions look off / model performs poorly**
Check that `players.csv` wasn't modified or truncated, and that the
notebook printed reasonable metrics (R² around 0.55-0.60 on the full
dataset) before saving the pickle.

## Notes

- The model predicts `log1p(market_value_in_eur)` internally and converts
  back to EUR (`expm1`) for display, since raw market value is heavily
  right-skewed.
- `requirements.txt` here is for **local development**. The version
  deployed on Hugging Face Spaces uses a slightly different
  `requirements.txt` (no `gradio` pin, since the Space's base image
  already provides it) — see the Space's Files tab if you need to compare.
